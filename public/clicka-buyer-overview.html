What You're Buying

A production-ready, multi-tenant online booking system for hair salons and beauty studios. One codebase, unlimited salons — each with their own branded public page, AI chat assistant, Stripe payments, and Telegram notifications for the owner.

Currently live in Bulgarian. Fully ready to be rebranded and relaunched in any language or market.

Features

Booking System

  • Unlimited salons from one deployment
  • Custom subdomain or custom domain per salon
  • Service catalog, staff profiles, working hours
  • Real-time slot availability
  • Stripe deposits and payments
  • Email confirmations

AI Chat Widget

  • Embedded on every salon's public page
  • Knows salon's services, prices, staff and FAQ
  • Guides clients through booking via chat
  • Powered by OpenRouter — swap any LLM
  • Rate-limited per IP

Telegram Bot

  • Instant booking notifications to salon owner
  • Admin commands via Telegram chat
  • Photo upload → auto-syncs to gallery
  • Native Telegram Bot API, no dependencies

Admin Dashboard

  • Booking management per salon
  • Services and staff management
  • Gallery and working hours config
  • Client notes and history
  • Google Reviews AI analysis

Rebranding & Localization

The system is currently live in Bulgarian, but all UI strings and date/currency formatting are centralized. Translating to English, German, Romanian, or any other language is a straightforward process. The multi-tenant architecture means different salons can operate in different languages from the same instance.
